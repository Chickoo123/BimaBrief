# Local-only source workbooks

For a full source rebuild, download the relevant official Excel workbooks directly from the [IRDAI Handbook page](https://irdai.gov.in/handbook-of-indian-insurance) and place them here as `Part II.xlsx` and `Part III.xlsx`.

These files are intentionally not included in the public release because their redistribution terms have not been verified. The published website is built from reviewed snapshots in `data/published/`. Do not commit raw workbooks, private policy documents or customer/claim data.
